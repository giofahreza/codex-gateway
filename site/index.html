Built around the actual gateway workflow.

IO Gateway is for operators who run many AI accounts and need predictable routing, account safety, and a direct place to test models.

1. Connect

Add provider accounts

Save Codex, Claude, Gemini, Copilot, GLM, and other account credentials on your server.

2. Route

Choose the accounts used first

Mark one or more accounts as Use first so they receive traffic before normal accounts.

3. Test

Try models in the dashboard

Run a quick prompt against any available model without creating a separate client API key.

4. Observe

Watch quota and errors

See account health, usage windows, cooldowns, reset timing, and attention states.

5. Protect

Issue scoped API keys

Limit each key by whole prompt size, provider prompt size, or specific account prompt size.

6. Alert

Notify before failure

Send Telegram or Google Chat alerts when auth, quota, or upstream state needs attention.

Dashboard control without exposing provider credentials.

Users call your gateway. Operators keep the upstream accounts private and manage routing, API keys, notifications, and model tests from one place.

Model testing is built in

Use Settings -> Test API to send a prompt through any model in the unified catalog.

Routing is explicit

Provider prefixes, custom aliases, and priority account flags make it clear where traffic goes.

Keys have guardrails

Set prompt-token ceilings for an API key globally, by provider, or by account before dispatch.

Custom models are real gateway routes.

Create ctm: aliases that hide provider complexity from clients while keeping fallback, account selection, and dashboard testing under operator control.

Stable alias names Expose names like ctm:research or ctm:coding instead of provider-specific model IDs.
Ordered fallback Route through the next target when a provider is cooling down, out of quota, or unavailable.
Provider and account targeting Point one alias at selected providers, specific accounts, priority accounts, or a mixed provider chain.
Direct Test API checks Try the alias from the dashboard before clients depend on it, without creating a client API key.
