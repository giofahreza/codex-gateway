Run it on your own server

Build the release binary, add credentials, and point clients at the gateway.

cargo build --release
cp config.example.json config.json
export CODEX_GATEWAY_KEY="your-shared-proxy-key"
./target/release/codex-gateway

Built for agent traffic

Long-running coding sessions need clear routing behavior and fast failure handling.

  • Retry another account before meaningful output reaches the client.
  • Cooldown accounts from quota reset timing, Retry-After headers, or bounded backoff.
  • Keep dashboard polling and model catalog refreshes off the hot request path.
  • Limit API key access by provider and account without exposing dashboard credentials.
