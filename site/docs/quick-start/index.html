Quick start

Type
Tutorial
Applies to
New local and server installs
Docs version
v0.1.11+
Updated
July 28, 2026

Use this tutorial to get IO Gateway running, open the operator dashboard, add upstream credentials, and verify that a model request reaches a provider account.

Before you start

  • Repository checkout Work from the IO Gateway source tree that contains Cargo.toml.
  • Rust toolchain Build the app with the installed Rust toolchain used by the server.
  • Provider credential Prepare at least one upstream account before testing real model calls.

Install and run

  1. 1
    Build the gateway.

    Run cargo build --release from the repository root.

  2. 2
    Create configuration.

    Start from the configuration reference and set listen, proxy_api_key, and auth_dir.

  3. 3
    Start the service locally.

    Run the binary with the config you want to test, then open the dashboard host and port from listen.

  4. 4
    Add a provider account.

    Use the provider account workflow before sending client traffic.

Verify

curl http://127.0.0.1:8319/health
curl http://127.0.0.1:8319/ready

After the health checks pass, use Test API from the dashboard to send a short prompt through one model route.

Next steps

  • Secure dashboard access Configure admin auth before exposing the service.
  • Create managed API keys Replace broad shared-key access with scoped keys and prompt-token limits.
  • Plan routing Use priority routing or custom models when traffic should prefer specific accounts.
